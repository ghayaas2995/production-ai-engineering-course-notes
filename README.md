# production-ai-engineering-course-notes
This repo serves as my collection and a resting place for notes prepared from each class of Krish Naik Academy's - Production AI Engineering course, starting July 2026. Notes are added each week as the recordings from the live sessions become available.

Not an Offical Course Material.

Document Organization - 

* Numbered sections following that class's actual progression, not a re-shuffled "textbook" order.
* Important callouts for anything the instructor explicitly flagged as important or interview-relevant — these get a fuller explanation than the surrounding material, not just a label.
* Quick-reference glossary at the end of each doc for terms, formulas, and PyTorch operations.
* Common Points of Confusion (Class Q&A) at the very end — real questions from class discussion, rewritten as clean Q&A pairs, covering the mix-ups that came up live.
* Written in second person ("you do X because Y") as a self-contained lesson for better understanding and follow through, not narrated as "the instructor said."

Disclaimers - 

* These documents reflect my own understanding and paraphrasing of live sessions. Errors, oversimplifications or missed topics are possible.
* Not a substitute for actually attending classes, watching the recordings or reading source papers. Use these notes as a refresher
